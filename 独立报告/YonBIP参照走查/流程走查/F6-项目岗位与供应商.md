# F6 项目岗位与供应商 · A 段

**岗位要同时呈现项目组织和项目基本分类。** 岗位页先带出组织，再由左树决定维护哪一类岗位。选中有下级的投资类也能增行。产品说明进一步写明：当前项目分类没有定义岗位时，沿父分类向上查找。经理岗位的唯一约束有文档依据，究竟跨哪些组织、分类检查，仍缺少足以判定的实例。

**路径**　档案维护人 → 项目管理／基础设置／项目人员／项目岗位 → 项目组织 → 分类 → 岗位行。项目经办人 → 项目启动／项目经理任命 → 查询任命书 → 本次缺必填组织。供应商维护人 → 动态建模平台／基础数据／供应商信息 → 集团或业务单元入口 → 选择范围 → 查询 → 有选中档案时才能继续验证分配。

## 没看到什么、为什么

- **岗位归属与重名。** 界面显示组织范围和分类，说明书确认按分类定义并向父级查找。跨分类能否同名、经理唯一性覆盖哪一层，缺存量正反例和服务端校验。不能将全公司唯一写进规则。
- **岗位录入与任命。** 单行草稿和取消已有截图。多行里一行出错是否影响其他行、停用岗位是否仍可任命、历史单据怎样显示停用值，均未验证。参照资料明确被引用不能删除，现场没有对现有档案尝试删除或停用。
- **供应商分配。** 集团页与业务单元页均有分配入口。两处查不到行，无法确认分配后的归属、组织可改字段、分配的撤销方式或历史归属。导入、导出仅记录入口。
- **清单第 6 节。** 空选状态不能验证多行操作、复制、批改、联查定位，单角色不能验证跨角色字段能力。本次没有执行保存、重复提交、并发写入或任何实际分配。
