# F4 资产借用到归还 · A 段

**本条卡在必填的资产组织。** 申请页的组织参照初始为 0 条，包含停用后仍为 0，按“演示”搜索也未找到候选。申请、申请处理、借用单、借用归还和台账尝试放宽日期后，系统提示必输项未填。因此这些空白表格不能证明没有存量资产业务。

**流程图**　借用申请人 → 资产借用申请 → 处理人员／申请处理 → 选择来源行、发放或不发放 → 借用单维护 → 归还经办人／借用归还 → 借用归还台账。页面入口及处理动作已看到，角色分工来自流程清单；没有观察到申请行真正变成借用单或归还单。

## 没看到什么、为什么

既有空白申请表单能看到资产组织、借用部门、借用人和禁用的增行；哪些字段填完才能解锁尚未验证。本次 A 段只找存量，没有填写新单。没有发放、部分归还或超期样本，不能推导处理后是否仍能改原申请、是否保留行焦点、剩余数量和超期提醒的算法。选多行后批改、复制、离开提示、批量部分失败、并发、重复提交、打印任务和不同处理角色的字段能力均未观察到。
