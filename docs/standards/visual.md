# 视觉与字段展示

浅色、高信息密度。观感按参照原型 `examples/ref-prototype/`（用户 2026-11-25 定），原型的数值是从参照站截图量的。

## token

- 颜色、字号、圆角、行高按原型。原型和正文不一致的地方按正文。
- 值只写在 `src/theme/`：`theme.css`（Element Plus 变量）、`tokens.css`（布局、表格、状态色、vxe 变量）、`controls.css`（控件尺寸），其余代码只用 CSS 变量。
- 主色红只用在主按钮、查询、勾选、必填星号和活动页签；选中行、聚焦、开关、链接用蓝。
- 改颜色要重算对比度：文字不低于 4.5:1。占位、禁用、边框按原型，不受这条限制。

| 项 | 规则 |
|---|---|
| 字号（字号/行高） | 正文与表格 12/18，页签和导航 13/18，区块标题 14/20，页标题 18/24，计数 24/30 |
| 字体 | `Segoe UI` 在前、微软雅黑在后，数字取前者 |
| 字重 | 只用 400 和 700 |
| 间距 | 4、8、12、16、24、32 |
| 圆角 | 控件 3，浮层 4，首页卡片 8；列表和单据的面板是直角 |
| 尺寸 | 最小支持 1366；顶栏、页签、标题行、控件等高度以 `tokens.css` 为准 |

## 状态

- 状态只用 `StatusTag` 显示，五种语义：`draft` 草稿·关闭、`doing` 处理中、`done` 完成、`watch` 关注、`fail` 失败·阻断。前三种只显示文字，后两种带底色。页面只传语义和文字，不传颜色。
- 三套状态分开建模：单据状态（草稿、审批中、已通过）、业务状态（未生效、生效、冻结、终止）、行状态（待生成、部分生成、已生成）。

## 字段展示

| 字段 | 规则 |
|---|---|
| 金额 | 右对齐、`tabular-nums`、千分位、按币种精度；单币种写在列头，多币种逐行显示；负数用负号加红色 |
| 零与空 | 零显示 `0.00`，空值显示 `—`，同一模块不混用 |
| 合计 | 固定在表格最下面一行；写明范围：“本页合计 / 查询结果合计 / 已选合计”；不同币种分开合计；无税、税额、含税分列 |
| 日期 | 业务日期 `YYYY-MM-DD`，会计期间 `YYYY-MM`，时间 `YYYY-MM-DD HH:mm:ss`；纯日期按字符串传 |
| 编码、账号 | 按字符串处理，保留前导零；单号可复制、可联查；银行账号默认脱敏 |
| 参照 | 显示“编码 + 名称”，提交稳定 ID；历史单据显示制单时的名称，停用项标“已停用” |

## 金额录入

- 金额在界面、状态和接口里都是字符串，计算用 decimal.js（`src/shared/money/amount.ts`）。
- 录入只用 `AmountInput`：聚焦显示纯数字，失焦显示千分位，编辑中不重排文本。
- 科学计数法拒绝；超出小数位的非零数字拒绝，不静默舍入；拒绝时给出原因。
