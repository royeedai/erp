# 单据、参照、审批、核销

规范的最小单位是单据，不是增删改查页面。

## 单据页

自上而下：标题行 → 表头 → 明细 → 合计行。录入时按 [form.md](form.md#整页卡片) 的整页卡片。

| 项 | 规则 |
|---|---|
| 标题行 | 顶部固定；左边单号、主状态，右边可办动作；附件、联查、审批、打印是动作，不在下面另起区块 |
| 状态与金额 | 业务状态、生效状态和各类金额是表头字段，按组放 |
| 表头联动 | 改组织、供应商会使已选行失效时，先列出受影响的行 |
| 变更与执行 | 变更记录、补充协议、执行信息做成明细页签 |
| 当前值与历史 | 当前值、制单快照、异动记录分开 |

## 明细

| 项 | 规则 |
|---|---|
| 明细区 | 多张明细用页签，页签写行数，旁边写已选数；可整块收起 |
| 行操作 | 在明细区右上：增行、删行、复制行、批改、导入、导出，带全屏按钮；行不单独保存 |
| 禁用 | 表头未填够时禁用增行，并写明缺什么 |
| 行与键盘 | 行用稳定 ID；Enter 确认并到下一个可编辑格 |
| 错误 | 错误摘要能跳到“第 8 行·申请金额” |
| 复制 | 清掉行 ID、来源占用、审批与结算结果 |

勾选、序号、操作列、列设置、行高同 [list.md](list.md#列与行)。

## 树与参照

| 项 | 规则 |
|---|---|
| 树 + 列表 | 树可收起；能不能新增由接口返回，不看有没有子节点 |
| 档案参照 | 弹层：搜索、显示停用、包含下级，写明候选范围；多选在左下写已选数，点开看已选，跨页保留 |
| 选来源单 | 整页：返回、标题、查询区、表格；列出原额、已用、可用；底部左边“查看已选”和“几单几行”，右边是生成或确认 |

## 审批

- 办理在审批中心，工作台的计数也进这里；自己发起和要跟踪的在我的流程中心。
- 打开对应任务与单据版本，只放开本节点字段。
- 改金额并列显示原值、核定值、差额。
- 撤回、弃审、作废是三个不同动作。

## 核销、对账

- 本方在上、对方在下，各写行数、已选笔数与金额，各带全屏；底部常驻差额。
- 多对多要能录本次分配额。
- 范围不一致先提示，再判断是否对平。
