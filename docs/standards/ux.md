# 交互通则

## 导航与组织

| 项 | 规则 |
|---|---|
| 导航 | 不放常驻侧栏；左上角打开全部应用，按业务域和模块列；顶栏有面包屑和应用搜索 |
| 首页 | 固定为第一个页签，放待办计数、常用应用和本角色的任务 |
| 组织 | 每页用自己的组织类型（项目、财务、资产等），必填，放标题行或查询区第一个；不做一个管所有页面的全局组织 |

## 权限与动作

前端不按状态推断能做什么，只按接口返回的 `allowedActions`、禁用原因、字段读写能力渲染。权限码只在 `src/app/permissions.ts` 登记。

## 保存与提交

| 项 | 规则 |
|---|---|
| 按钮名 | 用保存、保存新增、保存提交；没有无占用草稿能力就不叫“暂存” |
| 副作用 | 会预占、会进审批的，在按钮旁写清，例如“保存后预占 ¥10,000.00” |
| 幂等与版本 | 带幂等标识和版本号；409 时并列显示“你的值 / 最新值”。全部由封装处理，页面不自写 |
| 超时 | 先按操作号查结果；写操作不自动重试，付款和发指令永不自动重发 |
| 预算、计划控制 | 三级：提示 / 预警（填理由可继续）/ 强控（拦截并给出差额） |

## 删除与纠正

- 单据只有草稿能删；已生效走变更、作废、红冲。
- 已引用不能删：给原因和替代动作（改为停用）。
- 不可逆动作二次确认并必填原因。

## 批量、导入、导出

| 项 | 规则 |
|---|---|
| 批量 | 写明“当前页 / 已选 / 筛选全部”；跨页全选由服务端存筛选快照；结果逐行可查，只重试明确可重试的行 |
| 导入 | 模板 → 上传 → 预检 → 确认 → 结果；错误给行号、列名、原因；不默认选覆盖，全量覆盖要显示将替换的行数 |
| 超限 | 写明被挡下多少，不静默丢弃 |
| 导出、打印 | 服务端生成；大任务进任务中心，可离页；下载时复核权限 |

## 反馈

| 情况 | 方式 |
|---|---|
| 成功 | 全局提示 `toast` |
| 字段错误 | 留在字段旁 |
| 需要处理的失败 | 对话框列明细，不用会自动消失的提示 |

不用常驻通知，它会盖住查询条件。

## 页签与离开

- 默认开多页签，最多 8 个；未保存显示圆点。
- 关闭页签、返回、切组织前都检查未保存。
- 财务明细不写浏览器持久存储。

## 快捷键

Ctrl+S 只在有安全草稿时可用；审批、删除、付款不设单键触发。
