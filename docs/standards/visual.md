# 视觉与字段展示

浅色、高信息密度、克制。颜色只用来表达状态和可操作性，阴影只给浮层。

## token

- 颜色、字号、圆角用自己的 token，不跟参照站。
- 值只写在 `src/theme/theme.css`（Element Plus 变量）和 `src/theme/tokens.css`（布局、表格、状态色、vxe 变量），其余代码只用 CSS 变量。
- 改颜色要重算对比度：文字不低于 4.5:1；输入框边框对白现为 3.12:1，不再降低。

| 项 | 规则 |
|---|---|
| 字号（字号/行高） | 正文与表格 14/22，辅助 12/18，区块标题 16/24，页标题 20/28，核心金额 24/32 |
| 字重 | 只用 400 和 600 |
| 间距 | 4、8、12、16、24、32 |
| 圆角 | 控件 4，面板 6，浮层 8 |
| 宽度 | 最小支持 1366，页边距 16；其余布局尺寸以 `tokens.css` 为准 |

## 状态

- 状态只用 `StatusTag` 显示，五种语义：`draft` 草稿·关闭、`doing` 处理中、`done` 完成、`watch` 关注、`fail` 失败·阻断。页面只传语义和文字，不传颜色。
- 三套状态分开建模：单据状态（草稿、审批中、已通过）、业务状态（未生效、生效、冻结、终止）、行状态（待生成、部分生成、已生成）。

## 字段展示

| 字段 | 规则 |
|---|---|
| 金额 | 右对齐、`tabular-nums`、千分位、按币种精度；单币种写在列头，多币种逐行显示；负数用负号加红色 |
| 零与空 | 零显示 `0.00`，空值显示 `—`，同一模块不混用 |
| 合计 | 固定在表格最下面一行；写明范围：“本页合计 / 查询结果合计 / 已选合计”；不同币种分开合计；无税、税额、含税分列 |
| 日期 | 业务日期 `YYYY-MM-DD`，会计期间 `YYYY-MM`，时间 `YYYY-MM-DD HH:mm:ss`；纯日期按字符串传 |
| 编码、账号 | 按字符串处理，保留前导零；单号可复制、可联查；银行账号默认脱敏 |
| 参照 | 显示“编码 + 名称”，提交稳定 ID；历史单据显示制单时的名称，停用项标“已停用” |

## 金额录入

- 金额在界面、状态和接口里都是字符串，计算用 decimal.js（`src/shared/money/amount.ts`）。
- 录入只用 `AmountInput`：聚焦显示纯数字，失焦显示千分位，编辑中不重排文本。
- 科学计数法拒绝；超出小数位的非零数字拒绝，不静默舍入；拒绝时给出原因。
