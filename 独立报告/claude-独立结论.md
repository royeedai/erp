# Claude 独立结论（写于阅读 codex 报告之前）

## A. 业务判断
1. 规范的最小单位应是“单据生命周期”，不是“增删改查页面”。词频：审批 855、下游生成 547、账表 339、集团/组织两级 279、联查追溯 271、提交收回 262、变更 243、冻结作废红冲 239、对账核销 221；而“附件”58、“移动”41。
2. 文档覆盖缺口：OA 关键词 0 次（公文/考勤/请假/印章全 0）；应收应付只作为下游出现（应付单 pm18/asset18），账龄 4、坏账 0。四大场景里 OA 和 AP/AR 主体没有需求文档。
3. 三套状态必须分开：单据状态 / 业务(合同)状态 / 行状态（pm p41“单据状态和合同状态分离”、treasury p65 行级“待生成/已部分生成”）。
4. “删除”在财务里基本不是删除：草稿才可删，生效后只有收回/弃审/变更/作废/红冲/止付/关闭。
5. 最难的 5 个：可编辑明细表、参照选择、拉单/推单+回写、双栏核销匹配、变更版本对比。审批中可改字段（treasury p65、asset p62/74/75）要求字段权限是“状态×角色”二维。
6. 甘特、GIS、大屏、Excel 端计划编制、移动端、CA/电子签章 不进 CRUD 基座。

## B. 技术选型
- React 19 + TS 6.0.x + Vite 8 + antd 6。TS 不上 7：typescript-eslint 8.74 peer 为 <6.1.0。
- 不用 Umi Max：@umijs/plugins 依赖 pro-components ^2 + react-query v4。
- ProComponents：2.8.10 绑 antd 4/5（antd5 一年维护期 2025-11-21 起已到期，最后版本 5.29.3 于 2025-12-18）；支持 antd6 的 v3 16 个月仍在 beta 通道。→ 业务代码不得直接 import；要么不用，要么锁死版本只在封装层内用。倾向：列表页先用 antd 6 原生 Table/Form 组合封装，不依赖 beta。
- 可编辑明细：≤50 行 antd Table+Form；大明细 AG Grid Community（单元格编辑/虚拟化/列固定/键盘），注意 区域选择、剪贴板、主从、Excel 导出、分组 在企业版（$999/人）。
- 备选 Vue：Element Plus 2.14 + vxe-table 4.24，两者都是稳定版，表格能力对 ERP 最完整；风险是 vxe 基本单人维护（3502 次提交 vs 次席 6 次，1347 open issues），区域选取/复制粘贴是收费版。如果后端/团队是 Vue（若依/芋道/Jeecg），应选它。
- 多页签保活用 React 19.2 内建 <Activity>，不用 react-activation。
- 请求 TanStack Query 5 + orval(OpenAPI)；zustand 只放 UI 状态；金额用字符串 + decimal.js。
- Excel 导入导出、打印放服务端：npm xlsx 0.18.5 有 CVE 且停更，exceljs 最后发版 2023-10。
- 审批：一期只做审批轨迹/操作，不做设计器；要设计器用 LogicFlow（Apache-2.0），bpmn-js 有水印许可。
- ESLint 10（自定义 no-restricted-imports/禁硬编码颜色）+ antd 官方 CLI 的 lint/mcp 作为 AI 护栏。

## C. 视觉
- 主色 #1D5BBF（对白 6.36，antd 默认 #1677FF 只有 4.10），成功 #177544 类，警告 #B45309，错误 #C8322B；布局底 #F3F5F8，容器白，边框 #DDE2EA，表头 #F5F7FA。
- 字号 14/表格 13；控件高 32，行内编辑 28；表格行 36；圆角 4/6；间距 4 的倍数；阴影只给浮层。
- 金额右对齐、tabular-nums、千分位、两位小数、负数红+负号；空值“—”与 0.00 区分；币种放列头或前缀；编码等宽可复制可穿透。
- 6 个语义状态色，不按文案配色。

## D. UX
- 动作由后端返回 availableActions + fieldAcl，前端不按状态自己推权限。
- 批量操作必须返回逐条结果；长任务进任务中心。
- 乐观锁 409 冲突给差异；提交用幂等键。
- 预算/计划控制三级：提示 / 预警可继续(需理由) / 强控拦截。
- 不可逆操作二次确认并要求原因（treasury p74-75）。
- 组织/期间/币种是全局上下文，切换要处理未保存页签。

## E. 落地
- 规格文件(spec) → 生成器 → AI 填业务 → 护栏（typecheck/eslint/spec 测试/Playwright 冒烟+截图）。
- 配置管：字段、列、查询、校验、权限码、状态动作矩阵、导入导出。代码管：联动计算、拉推单、核销、变更对比。
- AGENTS.md 单一真源，CLAUDE.md 引用它；黄金样例 4 个页面 + 一个完整单据。
- 不做低代码 JSON 引擎，Schema 用 TS 类型。

## F. 最不确定
1. React 还是 Vue（后端/团队决定）。
2. ProComponents v3 beta 能不能接受。
3. 明细行规模、是否需要 Excel 粘贴（决定是否上 AG Grid）。
4. OA / AP/AR 没有文档；是否多组织、多币种、信创浏览器、移动端。
