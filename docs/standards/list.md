# 列表

页面自上而下：标题行 → 查询区 → 状态页签 → 表格 → 合计行 → 底部。没有的部分不留空位。

## 标题行

| 项 | 规则 |
|---|---|
| 位置 | 图标和标题在左，组织、“显示停用”跟在后面；动作整组在右 |
| 动作顺序 | 新增、删除、复制 → 提交、启用、分配 → 业务动作、联查 → 导入、导出、打印 → 更多 → 刷新 |
| 要选中行的动作 | 没选时置灰；批量动作也在这里 |
| 作用于树节点或明细的动作 | 放那张表的右上，不放标题行 |
| 新增 | 能从来源单生成的，点开是来源菜单，“自制”排第一 |
| 主按钮 | 一页一个实心主按钮，排在动作最左；“查询”是图标按钮，不算 |

## 查询

| 项 | 规则 |
|---|---|
| 查询区 | 左起查询方案、一排常用条件；接着是查询、高级查询、更多、收起，清空条件在更多里 |
| 条件 | 不写标签，用占位文字；必填排最前，星号在框内最左 |
| 查询方案 | 默认方案由页面给，用户可另存 |
| 条件很多的页面（核销、报表） | 标题行放“查询”，点开对话框填条件 |
| 执行查询 | Enter 或点“查询”才执行 |
| 状态页签 | 有业务阶段的列表才有，带条数，“全部”在最后；点了立即查 |
| 主表、主子表 | 有明细的单据列表，在页签行右侧切换 |
| 条件与地址 | 非敏感条件进 URL，账号等敏感条件不进；返回时保住条件与行位置 |

## 列与行

| 列类型 | 默认宽度 |
|---|---|
| 序号 | 60 |
| 编码、短枚举 | 100 |
| 单号 | 150 |
| 名称 | 180 |
| 状态 | 88 |
| 金额 | 188 |
| 计数 | 104 |
| 组织 | 148 |
| 日期 | 108 |
| 时间 | 172 |
| 人员 | 108 |
| 操作 | 140 |

- 第一列勾选 45，第二列序号。
- 列不拉伸，右边余下的留空，用户可拖宽。
- 固定列：勾选、序号、编码、名称固定左，操作固定右；1366 宽首屏金额列完整露出。
- 操作列最多平铺 2 个，其余进“更多”。
- 列设置在表头最右端，用抽屉：待添加、已添加两栏，可搜索、可重置，行高也在这里切。
- 行高默认 24，可切 28 / 32，按用户记忆。

## 底部

- 已选条数在左，分页在右。
- 每页默认 50，可选 20 / 50 / 100 / 200。
- 合计的写法见 [visual.md](visual.md#字段展示)。

## 空态

分五种，各带下一步入口。加载中不露空态。

| 空态 | 要求 |
|---|---|
| 没数据 | 给下一步入口，例如新增 |
| 缺必填条件 | 没有执行查询，标出缺哪项，不显示“共 0 条” |
| 筛选为空 | 写明是筛选条件造成的，给调整或清空条件的入口；带着筛选不能只写“暂无数据” |
| 查询失败 | 保留条件，给重新查询；不显示“共 0 条” |
| 无权 | 写明缺什么权限，清掉不可见数据 |
