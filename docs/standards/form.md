# 录入

## 载体

| 场景 | 载体 |
|---|---|
| 可编辑字段一行放得下，没有子表和附件的档案 | 表内编辑 |
| 其余档案、所有单据 | 整页卡片 |
| 选参照、确认、批量改、高级查询 | 对话框，三档 520 / 640 / 860 |
| 只读内容、列设置 | 抽屉 |

## 表内编辑

| 项 | 规则 |
|---|---|
| 进入 | 点增行或修改，整张表进入编辑 |
| 增行 | 加在末尾，焦点进第一格，默认值先填好 |
| 列头 | 编辑时必填列带星，只读格用底色区分 |
| 动作 | 编辑中主按钮换成保存，取消在它右边；增行、删行照常，其余置灰 |
| 保存 | 一次保存全部改动的行 |
| 取消 | 回到原来的节点和选中行 |

键盘、稳定 ID、错误摘要和单据明细一样，见 [document.md](document.md#明细)。

## 整页卡片

| 项 | 规则 |
|---|---|
| 标题行 | 返回、标题、主状态在左；保存、保存新增、保存提交、取消在右，主按钮是保存 |
| 排布 | 多列：1366 宽 3 列，1600 起 4 列，2200 起 5 列；标签在控件左边、右对齐 |
| 分组 | 字段多就分组，组可折叠；制单、审批这类操作信息默认收起 |
| 主组织 | 第一个字段；没选之前其余字段置灰，并写明先选组织 |
| 带出的字段 | 用置灰的控件显示，不能改 |
| 子表 | 在字段下面，规则同 [document.md](document.md#明细) |

## 对话框

单列，标签对齐；控件定宽四档 110 / 200 / 280 / 400，不拉满；底部靠右，先确定后取消，“确定”写成具体动作。

## 通用

| 项 | 规则 |
|---|---|
| 分支字段 | 决定分支的字段在前；隐藏的不提交，切回时还原；对话框里从属字段放它下方灰底块 |
| 锁定字段 | 新增时提示“保存后不能修改”，编辑时显示文字加锁 |
| 校验 | 错误留在字段旁，保存失败滚动并聚焦第一个错误；服务端错误落到对应字段 |
| 关闭、取消、返回 | 有改动才确认，没填过直接走 |

保存的文案、幂等、版本号和冲突见 [ux.md](ux.md#保存与提交)。
